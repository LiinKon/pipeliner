# Pipeliner

Планы из шагов, соединённых трубами. Проекты — это папки, внутри них планы-схемы: ставишь стрелку — появляется шаг, пишешь название и, если нужно, описание.

Работает в браузере (телефон в приоритете, на ПК — горизонтальная схема) и отдельным приложением для Windows.

## Сайт

Включается через GitHub Pages: **Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

**На телефон как приложение:** открыть сайт → меню браузера → «Добавить на главный экран» (Android: «Установить приложение»). Откроется без адресной строки, со своей иконкой.

## Как пользоваться

| Действие | Как |
|---|---|
| Новый проект / план | меню справа (на ПК всегда открыто) → «+ Проект» / «+ План» — в списке появится пустая карточка, пишешь название, Enter |
| Новый шаг | нажать «+» под шагом или потянуть от него стрелку в пустое место |
| Ветка | ещё раз «+» у того же шага |
| Слить ветки | потянуть стрелку от «+» и отпустить на другом шаге (петли не создаются) |
| Прочитать описание | нажать на шаг |
| Редактировать | двойное нажатие или «Изменить» в раскрытом шаге |
| Удалить шаг | «Удалить» — соседние шаги соединятся сами, есть «Вернуть» |
| Поиск | на главном экране — по проектам, планам, названиям и описаниям шагов |
| Масштаб | щипок на телефоне; на ПК колесо — сдвиг, Ctrl + колесо — масштаб |

## Где хранятся данные

- **Сайт** — в браузере на этом устройстве, автоматически. Между устройствами не синхронизируется. Очистка данных сайта в браузере удалит проекты — делайте экспорт время от времени.
- **Приложение для ПК** — внутри приложения на этом компьютере, плюс резервные копии в выбранную папку (см. ниже).
- **Перенос и бэкап:** меню → «Экспорт всего» (файл `.json`) → на другом устройстве «Импорт из файла». Импорт ничего не затирает, проекты добавляются. Один проект: «⋯» в проекте → «Экспорт проекта в файл».

## Приложение для ПК (Windows)

То же самое, что сайт, но отдельной программой: своё окно (запоминает размер и место), работа без интернета, «Сохранить как…» вместо папки «Загрузки» и **автоматические резервные копии** в выбранную папку.

**Скачать:** раздел **Releases** справа на главной странице репозитория → `Pipeliner-setup-….exe`. Права администратора не нужны. Если Windows покажет «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае» (программа не подписана платным сертификатом).

**Резервные копии:** меню → «Резервные копии» → «Выбрать папку…». Приложение само пишет туда `Pipeliner — все проекты.json` (всегда свежая, через ~5 секунд после изменения) и копию за каждый день (хранятся 14 последних). Если выбрать папку в Яндекс.Диске / OneDrive / Google Drive, копии ещё и уезжают в облако. Там же — «Восстановить из копии (заменить всё)», например на другом ПК.

**Собрать новую версию:** поменять `version` в `desktop/src-tauri/tauri.conf.json` (например, `1.0.1`) и `APP_VERSION` в начале `app.js` → вкладка **Actions** → «Сборка приложения для ПК» → **Run workflow**. Через ~10–15 минут установщик появится в Releases. Интерфейс приложение берёт из файлов сайта в корне — правите сайт, пересобираете, и приложение обновлено.

## Файлы

- `index.html`, `style.css`, `app.js` — само приложение; `fonts/` — шрифты (локально, без интернета)
- `manifest.webmanifest`, `icon*` — установка на телефон и иконки
- `desktop/` — приложение для ПК (Tauri 2), `.github/workflows/desktop.yml` — его сборка
