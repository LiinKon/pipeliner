# Pipeliner

**Открыть: [liinkon.github.io/pipeliner](https://liinkon.github.io/pipeliner/)**

Pipeliner — это планы, нарисованные трубами. Любую задачу, сценарий или процесс можно разложить на шаги и соединить их в схему: что за чем идёт, где путь разветвляется и где ветки снова сходятся.

Сделан в первую очередь для телефона, на компьютере тоже работает. Ничего устанавливать не нужно, достаточно открыть ссылку.

## Как это устроено

- **Проекты** — это папки. В каждом проекте может быть сколько угодно планов.
- **План** — схема из шагов, соединённых трубами. Всё начинается с вентиля «Старт».
- **Шаг** — название и, если нужно, описание. Нажми на шаг, чтобы раскрыть описание.
- **Поиск** на главном экране ищет сразу по проектам, планам и тексту шагов.

## Как создать план

1. Открой меню справа и нажми «+ Проект». Появится пустая карточка, впиши название.
2. Внутри проекта нажми «+ План» и так же впиши название.
3. В плане нажми «+» у старта или потяни от него стрелку. Появится новый шаг, подсвеченный оранжевым, в него сразу можно писать.
4. Ещё раз нажми «+» у того же шага, и получится ветка. Чтобы свести ветки вместе, дотяни стрелку до другого шага.

Удалённый шаг можно вернуть кнопкой во всплывающем сообщении. Соседние шаги при удалении соединяются сами.

## Управление

| Что | Телефон | Компьютер |
|---|---|---|
| Новый шаг | нажать «+» под шагом | нажать «+» справа от шага |
| Прочитать описание | нажать на шаг | клик по шагу |
| Редактировать | двойное нажатие | двойной клик |
| Двигать схему | вести пальцем | тянуть фон или колесо мыши |
| Масштаб | щипок | Ctrl + колесо или кнопки справа внизу |
| Вся схема целиком | кнопка с рамкой справа внизу | то же |

## Где хранятся проекты

Всё сохраняется автоматически в браузере на том устройстве, где ты работаешь. На сервер ничего не отправляется.

- Телефон и компьютер видят разные проекты. Перенести их можно через меню: «Экспорт всего» сохранит файл `.json`, а на другом устройстве «Импорт из файла» добавит проекты, ничего не стирая.
- Если очистить данные сайта в браузере, проекты удалятся. Время от времени делай экспорт.
- Один проект можно выгрузить отдельно: «⋯» внутри проекта → «Экспорт проекта в файл».

## На главный экран телефона

Открой ссылку в браузере и выбери в меню «Добавить на главный экран» (на Android может называться «Установить приложение»). Pipeliner появится иконкой и будет открываться без адресной строки, как обычное приложение.

Сайт состоит из трёх файлов: `index.html`, `style.css` и `app.js`. Шрифты лежат в папке `fonts`, иконки и `manifest.webmanifest` нужны для установки на телефон. Сайт работает через GitHub Pages из ветки `main`.
