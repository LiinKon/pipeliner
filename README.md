# Pipeliner

Планы из шагов, соединённых трубами. Проекты — это папки, внутри них планы-схемы: ставишь стрелку — появляется шаг, пишешь название и, если нужно, описание.

Работает в браузере: телефон в приоритете, на ПК — горизонтальная схема.

## Сайт

Включается через GitHub Pages: **Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save**. Через минуту сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

**На телефон как приложение:** открыть сайт → меню браузера → «Добавить на главный экран» (Android: «Установить приложение»). Откроется без адресной строки, со своей иконкой.

## Как пользоваться

| Действие | Как |
|---|---|
| Новый проект / план | меню справа (на ПК всегда открыто) → «+ Проект» / «+ План» — в списке появится пустая карточка, пишешь название, Enter |
| Новый шаг | нажать «+» под шагом или потянуть от него стрелку в пустое место |
| Ветка | ещё раз «+» у того же шага |
| Слить ветки | потянуть стрелку от «+» и отпустить на другом шаге (петли не создаются) |
| Прочитать описание | нажать на шаг |
| Редактировать | двойное нажатие или «Изменить» в раскрытом шаге |
| Удалить шаг | «Удалить» — соседние шаги соединятся сами, есть «Вернуть» |
| Поиск | на главном экране — по проектам, планам, названиям и описаниям шагов |
| Масштаб | щипок на телефоне; на ПК колесо — сдвиг, Ctrl + колесо — масштаб |

## Где хранятся данные

- В браузере на этом устройстве, автоматически. Между устройствами не синхронизируется. Очистка данных сайта в браузере удалит проекты — делайте экспорт время от времени.
- **Перенос и бэкап:** меню → «Экспорт всего» (файл `.json`) → на другом устройстве «Импорт из файла». Импорт ничего не затирает, проекты добавляются. Один проект: «⋯» в проекте → «Экспорт проекта в файл».

## Файлы

- `index.html`, `style.css`, `app.js` — само приложение; `fonts/` — шрифты (локально, без интернета)
- `manifest.webmanifest`, `icon*` — установка на телефон и иконки
